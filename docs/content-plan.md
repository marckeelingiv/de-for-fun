# DE for Fun lesson production

The lesson series and production scripts are maintained in [Lesson Studio](https://github.com/marckeelingiv/lesson-studio). See the [canonical series plan](https://github.com/marckeelingiv/lesson-studio/blob/main/docs/de-for-fun-content-plan.md).

DE for Fun owns platform code, technical evidence, and demo prerequisites. Lesson Studio owns lesson plans, reusable presentation experiments, and post-production. Link supporting evidence to this repository and record source commits in lesson briefs. Make changes to production tools in Lesson Studio; they are no longer included in this data worktree.
